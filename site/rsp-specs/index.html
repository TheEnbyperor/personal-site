Rail Settlement Plan Barcode Specs

The specifications for UK Railway Barcoded Tickets, provided under the Freedom of Information Act.

The Specs

The following are the PDFs constituting the specification documents for barcoded ticketing:

  • RSPS1024 — Interoperable Barcode Ticketing — Code of Practice
  • RSPS3001 — Barcode Presentation, Key Management and Data Specification; Version: 02-03
  • RSPS3001 — Barcode Presentation, Key Management and Data Specification; Version: 03-00
  • RSPS3030 — Ticketing Specification — Ticket; Version: 05-02

They also reference the following Microsoft Excel files documenting the exact layout of binary fields:

  • RSPS3001 — Type 06 Encoding Information; Version: 02-03
  • RSPS3001 — Type 08 Encoding Information; Version: 02-03

Background

The release of these documents is a result of appeals to the General Regulatory Chamber on the following FoI requests, on WhatDoTheyKnow:

  • London North Eastern Railway Limited
  • Northern Trains Limited
  • SE Trains Limited
  • Caledonian Sleeper Limited
  • TransPennine Trains Limited
  • ScotRail Trains Limited
  • Transport for Wales
  • Transport for Wales Rail Limited

Version 03-00 of the RSPS3001 was provided in response to a request by Harley Watson.
